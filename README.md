# Project Icons

A collection of icons for 18 projects. Each project has its own folder containing:

- `icon.svg` — scalable vector artwork for sharp display at any size.
- `icon.png` — 2048-pixel-wide raster artwork for tools that need PNG.

Use the SVG when you need to resize an icon. Use the PNG when your app does not support SVG.
